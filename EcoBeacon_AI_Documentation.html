Application Overview

What EcoBeacon AI is and what it does

EcoBeacon AI is a full-stack personal carbon footprint tracking web application. Users log daily activities across four categories, receive real-time emission calculations, earn gamification rewards, and are guided by an AI engine to reduce their carbon impact.

Core Features

Foundational functionality available to all users

🔐 User Authentication

Secure register/login flow using JWT tokens. Tokens are stored in localStorage under key eco_token. All protected routes require a valid Bearer token. Axios interceptors automatically inject the token on every request and redirect to /login on 401 responses.

Register Login JWT Protected Profile Update
📝 Activity Logging

Log activities across 4 categories. Each submission calculates emissions server-side, updates the Eco Score, checks for new badges, and updates the daily streak. A real-time emission preview is shown client-side as the user types — no API call needed.

🚗 Transportation ⚡ Electricity 🍽️ Food 🛍️ Shopping
📊 Emission Dashboard

The Dashboard displays four KPI stat cards (today, week, month, eco score), an Area Chart with toggle between stacked/total views, a Donut Chart for category breakdown, and an SVG arc Eco Score Gauge. Data is fetched in parallel via Promise.all.

🏆 Gamification

9 Badges are awarded for milestones: first log, activity count (10, 50), eco score thresholds (60, 80), streak length (7, 30 days), and eco-friendly choices. A Daily Streak counter increments when the user logs on consecutive days and resets if they miss a day.

Smart Pattern Recognition

Pattern AI

While filling the Log Activity form, the app fetches the user's recent history for the same activity type + category and compares the current input to their personal average. A contextual tip appears showing % above or below normal.

📊Above average: "28% more than your usual 18.5 for this category."
✨Below average: "15% less than your usual 18.5 — great job!"

Logic: inline hook useSmartTip() in LogActivity.jsx

AI Emission Forecast

Predictive

Visible on the Dashboard as the "AI Emission Forecast" panel. Analyses the user's last 30 days of activity to predict daily emissions for the next 7 days using a rolling average + linear trend algorithm. Displayed as an area chart with confidence level.

Algorithm
  1. Build date → daily emission map
  2. Calculate overall mean
  3. Split history into first/second halves
  4. Compute trend delta (slope)
  5. Project: mean + trend × day offset
Confidence levels
High
≥ 14 days of history
Medium
7–13 days of history
Low
< 7 days of history

Backend: backend/services/aiService.js → forecastEmissions() · Frontend: components/ForecastPanel.jsx

Anomaly Detection

Statistical

Available via GET /api/ai/anomalies/:userId. Scans the last 30 days of activities per category and uses a z-score statistical method to flag any activity with emission > 2× the category average and above the mean + 2σ threshold.

Example anomaly alert
⚠️ "This transportation activity emitted 12.75 kg CO₂ — 3.2× your usual average of 3.98 kg."

Backend: backend/services/aiService.js → detectAnomalies()

🔐 Auth Flow
  1. User submits credentials to POST /api/auth/login
  2. Server verifies password with bcryptjs
  3. JWT signed with process.env.JWT_SECRET (30d expiry)
  4. Token stored in localStorage as eco_token
  5. Axios injects Authorization: Bearer <token> on every request
  6. authMiddleware.js decodes token, attaches user to req.user
  7. 401 response → Axios interceptor clears token, redirects to /login
🤖 AI Pipeline
  1. Dashboard / LogActivity page loads
  2. Frontend calls GET /api/ai/suggestions/:userId
  3. Controller fetches last 30 days of activities from SQLite
  4. aiService.js analyses by type, generates prioritised suggestions
  5. Forecast: applies rolling average + linear trend, returns 7-day prediction
  6. Goals: pattern-analyses usage, generates 3 personalised targets
  7. Chat: keyword matching on POST /api/ai/chat, returns contextual reply

Demo Walkthrough

Step-by-step guide for a live product demonstration

ℹ️ Before demo: start backend (cd backend && npm start) and frontend (cd frontend && npm run dev). Default URLs: Frontend http://localhost:3000 · API http://localhost:5000
1

Register a new account

Navigate to /register. Fill in name, email, and password. Show that the account is created instantly with an Eco Score of 50. Login redirects to the Dashboard.

2

Log a car trip using NLP

Go to /log. In the blue "AI Natural Language Logger" box at the top, type "drove 25km to work" and press Parse. Watch as the form auto-selects Transportation → Car → 25 km. Click Apply, then Log Activity.

3

Show impact analysis

After setting a value, click "Show AI impact analysis" below the emission preview. The Impact Contextualizer appears showing trees needed, phone charges, TV hours, and carbon budget bars for the Paris target and world average.

4

Log 4–5 more activities

Log: beef meal (Food → Beef), 10 kWh electricity (Electricity → Standard), a flight (Transportation → Flight, NLP: "flew 300km"), a vegan meal. This gives the AI service enough data to generate meaningful analysis.

5

View the Dashboard AI Forecast

Navigate to Dashboard. Scroll past the charts to the "AI Emission Forecast" panel. Show the 7-day prediction area chart, trend direction (increasing/decreasing/stable), confidence level, and the personalised weekly goals below it.

6

Demonstrate AI Suggestions

In the SuggestionsPanel on the Dashboard, expand the high-priority suggestions. Show how suggestions are generated specifically for the activities logged (e.g., "Switch to Public Transport" if car trips were logged).

7

Chat with AI Assistant

Click the 🤖 floating button (bottom-right). Ask: "What is my biggest emission source?" — show the contextual response. Try a quick-question shortcut. Ask about the Paris Agreement target to demonstrate climate knowledge integration.

8

Show Badges & Streak

Scroll to the BadgesPanel on Dashboard. Show which badges have been earned (First Log, etc.). Navigate to Profile (/profile) to show the paginated activity history with delete functionality and the full badges grid.
